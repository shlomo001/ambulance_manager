# תוכנית: בית משפט ולשכת עורכי הדין במצפה הכוכבים (FiveM)

המטרה: להפוך את מצפה הכוכבים Galileo Observatory ב-GTA V לבית משפט פעיל ולשכת עורכי דין, כולל מפה, פנים המבנה, תפקידים ומערכות משחק.

---

## 1. החלטות שצריך לקבל לפני שמתחילים

| נושא | אפשרויות | המלצה |
|---|---|---|
| פריימוורק | ESX / QBCore / Qbox / Standalone | שכבת התאמה (bridge) שתומכת בכולם, עם ברירת מחדל ל-Qbox/QBCore |
| ספריות | ox_lib, ox_target, oxmysql | כן, הן הסטנדרט היום |
| פנים המבנה | MLO מותאם בתוך המבנה / חדרים במקום אחר עם טלפורט | שלב 1: טלפורט, שלב 2: MLO אמיתי |
| מערכת כלא וקנסות | הקיימת בשרת שלך | חיבור דרך ה-bridge |
| שפה | עברית / אנגלית | עברית, עם קובץ תרגום (locales) |

> חשוב לדעת: במצפה הכוכבים ב-GTA V אין פנים שאפשר להיכנס אליו. הדלת סגורה ואין חדרים. לכן צריך MLO (פנים מותאם), או לשים את החדרים במקום אחר ולהעביר שחקנים בטלפורט.

## 2. חלוקת המבנה

לפי התמונה: כיפה מרכזית גדולה, שתי כיפות צד, שני אגפים ארוכים ורחבה קדמית.

| אזור במבנה | ייעוד חדש |
|---|---|
| כניסה ראשית ומדרגות | כניסה לבית המשפט ובידוק ביטחוני (גלאי מתכות, שומרים) |
| לובי מתחת לכיפה הירוקה | מזכירות בית המשפט, הגשת תיקים ולוח דיונים |
| כיפה מרכזית גדולה | **אולם הדיונים הראשי** (שופט, תביעה, הגנה, דוכן עדים, קהל) |
| כיפה שמאלית | **לשכת עורכי הדין**: משרדי הלשכה, חדר מבחנים, טקס השבעה |
| כיפה ימנית | לשכות השופטים וארכיון |
| אגף מערבי | אולם דיונים קטן (תעבורה ותביעות קטנות) ותאי מעצר זמניים |
| אגף מזרחי | משרדי עורכי דין להשכרה, ספרייה משפטית וחדר ישיבות |
| רחבה וחניה | חניה ייעודית לשופטים, לעורכי דין ולרכבי ליווי עצירים |

### שינויים במראה החיצוני
- להחליף את הכיתוב "GALILEO OBSERVATORY" שמעל הכניסה לכיתוב "בית המשפט" (החלפת טקסטורה בקובץ YTD).
- להוסיף דגלים, שלט כניסה, עמדת שמירה ומחסומי חניה.
- לחסום את התיירים (scenario peds) ואת הטלסקופים באזור.
- להוסיף Blip במפה בשם "בית המשפט".

> קואורדינטות המבנה בערך `vector3(-425.0, 1123.0, 325.8)`. צריך לאמת במשחק ולקבוע נקודות מדויקות לכל אזור.

## 4. מערכות

### 4.1 לשכת עורכי הדין (`court_bar`)
- **מבחן לשכה**: מבחן אמריקאי ב-UI עם מאגר שאלות, ציון עובר ותקופת המתנה בין ניסיונות.
- **רישיון עורך דין**: פריט או תעודה במלאי, עם מספר רישיון.
- **פנקס עורכי הדין**: רשימה ציבורית שאפשר לחפש בה (שם, מספר רישיון, סטטוס).
- **טקס השבעה**: אנימציה ונקודה ייעודית באולם הלשכה.
- **ועדת אתיקה**: תלונות, השעיה ושלילת רישיון.
- **דמי חבר**: תשלום חודשי אוטומטי.
- **משרדים להשכרה**: עם דלת נעולה וגישה לבעלים בלבד.

### 4.2 ניהול תיקים (`court_core`)
- סוגי תיקים: פלילי, אזרחי, תעבורה וערעור.
- מחזור חיים של תיק: הגשה ← פתיחה ← קביעת דיון ← דיון ← פסק דין ← ביצוע ← סגירה.
- צירוף צדדים: נאשם או תובע, נתבע ועורכי הדין של כל צד.
- ראיות: טקסט, קישור לתמונה, דוחות משטרה ופריטים מהמלאי.
- הערות פרוטוקול נשמרות אוטומטית לתיק.

### 4.3 אולם הדיונים
- ישיבה במקומות קבועים: כיסא שופט, שולחנות הצדדים, דוכן עדים וספסלי קהל.
- פטיש שופט עם צליל ופקודת "שקט באולם" שמשתיקה זמנית את הקהל בקול (pma-voice).
- **מצב דיון**: שופט פותח דיון, ומעכשיו הכול מתועד לפרוטוקול.
- השבעת עד: אינטראקציה בדוכן העדים.
- מסך באולם להצגת ראיות (DUI או טקסטורה מתחלפת).

### 4.4 פסקי דין וביצוע
- קנס: חיוב אוטומטי מהבנק, עם תמיכה בתשלומים.
- מאסר: חיבור למערכת הכלא בשרת.
- שלילת רישיון נהיגה או רישיון נשק.
- זיכוי או מחיקת רישום.
- צווים: צו מעצר וצו חיפוש, שמופיעים ב-MDT של המשטרה.

### 4.5 טאבלט / ממשק (`court_ui`)
- טאבלט NUI (React או Vue) עם הלשוניות: תיקים, לוח דיונים, פנקס עורכי דין, צווים ופסקי דין.
- התראות: זימון לדיון ותזכורת 10 דקות לפני הדיון.
- עמוד ציבורי עם לוח הדיונים של היום.

### 4.6 ביטחון ולוגים
- גלאי מתכות בכניסה, שמתריע כשנכנסים עם נשק.
- אזור ללא נשק בתוך המבנה.
- לוגים לדיסקורד (Webhook): פתיחת תיק, פסק דין, הנפקת רישיון וצווים.
- כל פעולה רגישה נבדקת גם בצד השרת. אין לסמוך על הלקוח.

## 5. מבנה הריפו

```
resources/[court]/
  court_core/      # לוגיקה, תיקים, דיונים, פסקי דין, bridge לפריימוורק
  court_bar/       # לשכת עורכי הדין: מבחן, רישיונות, פנקס, משרדים
  court_ui/        # טאבלט NUI
  court_map/       # stream: MLO, טקסטורות, ymap של פרופים וחסימת scenarios
sql/
  install.sql      # טבלאות
docs/
  PLAN.md
```

### טבלאות (oxmysql)
- `court_cases`: מזהה, סוג, סטטוס, כותרת, יוצר ותאריכים.
- `court_case_parties`: תיק, שחקן ותפקיד בתיק.
- `court_hearings`: תיק, מועד, אולם, שופט וסטטוס.
- `court_evidence`: תיק, סוג, תוכן ומגיש.
- `court_verdicts`: תיק, תוצאה, קנס, זמן מאסר ושופט.
- `court_warrants`: סוג, יעד, סטטוס ותוקף.
- `bar_licenses`: שחקן, מספר רישיון, סטטוס ותאריכים.
- `bar_exam_attempts`: שחקן, ציון ותאריך.
- `bar_complaints`: מתלונן, עורך דין, תוכן והחלטה.
